# Backend Quản lý thu chi – Implementation Plan

**Goal:** Dựng backend ASP.NET Core Web API đầy đủ use case trong spec, có kiểm thử tự động. Frontend Flutter thuộc kế hoạch 2.

**Architecture:** Gồm 1 project Web API, chia tầng theo thư mục:
- `Domain/` chứa 13 lớp, đúng tên và phương thức như sơ đồ lớp Hình 4.1. Quy tắc nghiệp vụ nằm trong lớp, vi phạm thì ném `DomainException`.
- `Services/` điều phối: tải dữ liệu, gọi phương thức domain, lưu trong 1 transaction.
- `Controllers/` chỉ chuyển DTO, không chứa logic.

**Tech Stack:** .NET 10, ASP.NET Core Web API, EF Core (SQL Server khi chạy, SQLite in-memory khi test), BCrypt.Net-Next, JWT Bearer, ClosedXML, Swashbuckle, xUnit + FluentAssertions + Microsoft.AspNetCore.Mvc.Testing.

**Spec:** `docs/thiet-ke/2026-11-07-quan-ly-thu-chi-design.md`. Mã quy tắc R1–R10 ở mục 4 của spec. Danh sách route ở mục 6.

## Global Constraints

- **.NET:** dùng .NET 10. Nếu máy nhóm không cài được thì dùng bản LTS cao nhất cài được và ghi vào README.
- **Đặt tên:** tên lớp, thuộc tính, phương thức theo Hình 4.1, viết PascalCase tiếng Việt không dấu. Ví dụ: `Vi.TruTien`, `NganSach.KiemTraVuot`, `MucTieuTietKiem.NapTien`.
- **Thông điệp lỗi:** tiếng Việt có dấu, đúng nguyên văn spec khi spec có ghi. Ví dụ "Số dư ví không đủ", "Không nhận dạng được hóa đơn".
- **Tiền:** dùng `decimal`, cột `decimal(18,2)`, đơn vị VND.
- **Thời gian:** mọi "hôm nay / tháng này / cuối tháng / giờ nhắc" tính theo **giờ Việt Nam (UTC+7)** qua `IDongHo`. Không gọi `DateTime.Now` trong Domain hay Services.
- **Route:** tiền tố `/api`, đúng danh sách ở mục 6 của spec.
- **Mã lỗi HTTP:** 400 `{message, errors?}` / 401 / 403 / 404 / 500.
- **Bí mật:** API key Gemini và khóa JWT để trong `appsettings.Development.json` hoặc user-secrets. File này đã nằm trong `.gitignore`, không bao giờ commit.
- **Transaction:** mọi thao tác ghi nhiều bảng phải nằm trong một `SaveChanges` hoặc một transaction.

## Review Focus

Các trường hợp spec không nói thẳng nhưng dễ gây lỗi khi dùng thật. Mỗi dòng có test ở task chịu trách nhiệm.

1. **Giờ server là UTC, người dùng ở UTC+7.** Giao dịch lúc 00:30 ngày 1 giờ Việt Nam phải tính vào tháng mới. Test ở Task 1 (`DongHoVietNam`) và Task 11.
2. **Giao dịch có ngày thuộc tháng khác.** Chỉ được cập nhật ngân sách của **tháng của giao dịch**, không phải tháng hiện tại. Test ở Task 11.
3. **Sửa hoặc xóa giao dịch làm ví âm.** Ví dụ xóa một khoản thu mà tiền đã tiêu hết, hoặc đổi thu thành chi. Phải từ chối với "Số dư ví không đủ" và **CSDL không thay đổi**. Test ở Task 11.
4. **Ảnh hóa đơn không hợp lệ.** Gồm: sai định dạng, lớn hơn 5 MB, Gemini lỗi, Gemini trả JSON hỏng. Tất cả phải trả 400 với thông điệp tiếng Việt, không được trả 500. Test ở Task 13.
5. **Tham số lọc lạ.** Với `tu > den` trả 400. Với `trang` vượt quá số trang hoặc `trang <= 0` trả danh sách rỗng hoặc mặc định trang 1. Test ở Task 11.
